# CloudOps Manager

## Description

CloudOps Manager est une plateforme web de gestion et de supervision des ressources cloud.

L'application permet :

- La gestion des projets
- La gestion des équipes
- La gestion des serveurs VPS/VM
- La gestion des applications déployées
- Le monitoring CPU/RAM
- La gestion des alertes et incidents
- La visualisation d'un dashboard global
